# 高科大第一校區 GTA · Grand Theft Campus

國立高雄科技大學第一校區（燕巢／楠梓）的 Three.js 3D 開放世界遊戲。單一 HTML 檔，直接用瀏覽器開啟 `index.html` 即可遊玩（需連網載入 three.js CDN）。

## 操作
| 按鍵 | 功能 |
|---|---|
| WASD | 移動／駕駛（手機：左側浮動搖桿，推到底自動跑；手機沒有跑步、視角按鈕） |
| 滑鼠 | 第三人稱視角 |
| SHIFT / SPACE | 奔跑 / 跳、手煞車 |
| F | 情境動作：上下車、騎機車、騎腳踏車／借 YouBike、搭話、摸狗（手機：靠近才出現的大按鈕） |
| J | 任務清單（手機：上方「任務」） |
| G | 切換畫質 低／中／高（手機：上方「畫質」；開始畫面也能選） |
| M／點小地圖 | 大地圖（點擊傳送或設導航、可搜尋建築） |
| N / Y / L / H | 白天→黃昏→夜晚 / 下雨 / 大燈 / 喇叭（腳踏車是鈴鐺） |
| Esc | 設定（畫質、時間天氣、音量、靈敏度、鏡頭距離；手機：搖桿與按鈕大小、震動、拖曳調整按鈕位置） |
| R | 回到行政大樓 |

## 特色
- 道路、建築輪廓、停車場、球場、鴴池依 OpenStreetMap 並對照衛星圖重建
- 每棟 2～4 個出入口，位置依 Google 衛星圖對照真實的雨遮、台階與步道
- 室內格局依學校官方「避難逃生平面圖」重建：教室、廁所、走廊、大廳、樓梯的位置都照真實平面（16 棟），23 棟都能走進去、爬到頂樓
- 校園會動：遊戲時鐘＋上下課鐘聲，上課時教室坐滿學生、老師在講台講課，下課走廊湧出人潮，午休學餐客滿
- 室內外碰撞（牆、樓梯扶手、桌椅、路燈、球門、球網、車擋、公車亭等），不穿模
- 停車場的機車與汽車可騎可開（汽車最高 90 km/h、機車 60 km/h），校內 NPC 車輛、國道車流與行人
- 腳踏車：中軸車架、宿舍門口的腳踏車與 YouBike 站的公共腳踏車都能騎；用踩踏力＋風阻＋坡度計算，平路約 25 km/h，上大學橋引道掉到約 15 km/h，下坡滑行會越來越快
- 大學橋兩端：橋台平台、擋土牆路堤（黃色護牆延伸下來）、約 6.7% 的固定坡度＋豎曲線，人行步道改為三段樓梯＋休息平台
- 依 Google 街景修正：大學路大門、電資黃色門架、管院玻璃圓塔與廣場、外語柱廊、橋東階梯劇場、太陽能車棚

- **校園任務**：10 個任務（另有社團招新、夜間巡邏、腳踏車計時賽、雨天送傘），綠色導航線沿道路帶路；原本 6 個任務（第一節要點名、YouBike 跨橋、學餐外送、圖書館還書、機車移車、校園巡禮），地圖上的黃色「!」按 F 接任務，綠色光柱是目標；限時任務、學分與最佳時間（存在瀏覽器）
- 圖書資訊大樓：大門在二樓，東北角有旋轉樓梯上到二樓平台（依 Google 街景）；平台下方是一樓國際會議廳入口
- 夜晚與黃昏路燈會亮（地面光暈＋附近真實光源）、下雨天氣；NPC 騎機車、腳踏車在校園道路上跑，路人會讓車
- 財金二樓中庭大階梯、學生活動中心二樓空橋、樂群樓綠色鋼構空橋（依街景與衛星圖）
- 路人經過會講話，按 F 可以搭話；校園裡藏了 4 個彩蛋
- 手機：建議橫拿；全螢幕、可「加入主畫面」當 App 玩

開發進度與接手說明見 [PROGRESS.md](PROGRESS.md)。
